DT-Faltung Schritt für Schritt

Pick a value of n, then see how y[n] comes from the overlap of x[i] with the flipped and shifted impulse response g[n−i]. Signale & Systeme, Kap. 6, Folie 151–152.

y[n] = (x ∗ g)[n] = Σi x[i] · g[n − i]

Output n
n = 2
x[i]input, stays fixed
g[n − i]g mirrored at i = 0, then moved right by n
x[i] · g[n − i]multiply column by column, then add
y[n]sum of the products, one value per n

Same result with the row method (Folie 152)

Each input sample x[k] sends out its own copy x[k]·g[n−k]: g scaled by x[k] and delayed by k. Adding each column gives y[n]. Click a column to jump there.

How to do it by hand

  1. Flip g: g[−i] is g mirrored at i = 0.
  2. Shift by n: in g[n−i], the sample g[0] now sits at i = n.
  3. Multiply the values that lie on top of each other, x[i]·g[n−i], and add them up.
  4. Check: in every product, the two indices add up to n, e.g. y[3] = x[0]g[3] + x[1]g[2] + x[2]g[1] + x[3]g[0].
