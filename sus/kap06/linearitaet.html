Linearität & Zeitinvarianz testen

The six systems from Aufgabe 1 of the Kap. 6 Übungsklausur. Pick one, then run the two tests from Folie 144–145: scale the input (λ-test) and delay it (shift test). The test input is a short pulse.

Test 1Linearität: λ-Test

Scale the input by λ. A linear system gives exactly λ times the old output, so the two curves lie on top of each other.
